# Clover Client
Clover Client is a client mod originally created by 85cs, and after the project was abandoned, it was revived by 85cs and Itelcan3. The project requires Java 8 installed and mixins installed. The entire directory should contain files ready for manual compilation.

# To use
To use and config the client you can use the chat command: **/clover** and you can use /clover**autoclicker, autoblock, chams, esp, storageesp, mobesp, freecam**. All of this have a lot of methods you can use the module like Fill or Outline for StorageESP, 2d or 3d for player esp etc.
